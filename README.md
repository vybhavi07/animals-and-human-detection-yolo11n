🐾 Animals and Human Detection using YOLO11

An AI-powered object detection project developed using Roboflow and YOLO11 to detect humans and animals from live webcam input and uploaded images.

---

📌 Project Overview

Animals and Human Detection is a computer vision project that uses an object detection model to identify four different classes: Human, Cow, Dog, and Goat.

The model detects objects, identifies their class labels, and displays bounding boxes with confidence scores around the detected objects.

The project was developed using Roboflow and YOLO11, providing practical exposure to AI, deep learning, and computer vision.

🎯 Objectives

- Develop an AI-based object detection system.
- Identify humans and different animal categories.
- Perform detection using a live webcam.
- Detect multiple objects from uploaded images.
- Understand the practical implementation of YOLO-based object detection.

⚙️ Working Principle

The system works through the following steps:

1. Dataset Preparation: Images containing humans, cows, dogs, and goats are collected and labelled.
2. Model Training: The labelled dataset is used to train the object detection model through Roboflow.
3. Input Acquisition: The system receives input through a live webcam or an uploaded image.
4. Object Detection: The trained YOLO11 model processes the input and identifies the objects.
5. Prediction: The model generates class labels, confidence scores, and bounding boxes.
6. Output Display: The detected objects are displayed with their respective bounding boxes.
